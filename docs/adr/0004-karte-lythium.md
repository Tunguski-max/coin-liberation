# ADR 0004: Karte Lythium

**Status:** Akzeptiert (2026-10-17)

## Kontext
Gesucht war eine Karte im passenden Setting mit einer Stadt, die als Hauptstadt taugt,
und 15–20 Ortschaften im Umkreis.

## Entscheidung
Lythium.

## Begründung
- Afghanistan-Setting passt zur Taliban-ähnlichen Miliz.
- Die Gruppe kennt die Karte aus Hearts and Minds.
- KP Liberation hat eine offizielle Lythium-Fassung (Missionsbasis vorhanden).

## Folgen
- Zusätzliche Mod-Abhängigkeiten: **Lythium** und **Jbad** (von Lythium benötigt).
- Alternative ohne Zusatzmod wäre Takistan (CUP Maps) gewesen.
